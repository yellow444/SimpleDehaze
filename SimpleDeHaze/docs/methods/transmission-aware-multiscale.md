# Transmission-aware multiscale: Lab-L, HSV-V и edge-aware bands

Статус: реализованный экспериментальный метод. Основной класс —
[`TransScaleLaplacianMethod.cs`](../../Methods/TransScaleLaplacianMethod.cs), зафиксированный
validation-вариант —
[`TransmissionAwareHsvEdgeMethod.cs`](../../Methods/TransmissionAwareHsvEdgeMethod.cs).

## Что сравнивается

Физическая часть во всех вариантах одинакова: CAP и DCP дают карту пропускания, guided filter
уточняет её, восстановление использует локальное поле атмосферного света, затем выполняется одна
и та же постобработка. Меняются только два фактора:

| `space` | Скаляр для полос |
|---:|---|
| `0` | Lab-L; прежний default |
| `1` | HSV-V; Hue и Saturation не фильтруются как линейные сигналы |

| `basis` | Многомасштабный базис |
|---:|---|
| `0` | Gaussian/Laplacian pyramid с уменьшением разрешения |
| `1` | полноразмерные residual bands между последовательными Domain Transform smoothings |

Для edge-aware RGB-пути остаток строится по линейной яркости и одинаковой добавкой возвращается в
линейные RGB-каналы. Для HSV-пути меняется только V, а H/S сохраняются. Структурные переключатели
не участвуют в автоматическом подборе: это абляции, а не непрерывные параметры.

## Общий гейт полос

Для полосы масштаба `l` используется ограниченный коэффициент

```text
G_l(x) = gain_l * max(richness(x), floor) * gate(t(x), l),
```

где `gate` монотонно растёт по `t` для мелких деталей, а на крупных масштабах не опускается ниже
безопасного пола. Поэтому в плотной дымке мелкий шум не должен усиливаться так же, как надёжная
текстура в прозрачной области. Тесты отдельно проверяют ограниченность, монотонность и точную
реконструкцию edge-aware разложения при единичном gain.

## Зафиксированный результат

На O-HAZE использовались неизменяемые split из manifest: 23 изображения validation для выбора
между четырьмя заранее заданными gain-конфигурациями и 22 изображения test ровно один раз.
Выбран `gFine=0.5`, `gMid=1.6`, `gCoarse=1.2`. Полные таблицы, команды и timing находятся в
[`transmission-aware-study-2026-08.md`](../research/transmission-aware-study-2026-08.md).

Новый HSV edge-вариант улучшил прежний full-profile baseline на test по PSNR на 14/22 и по SSIM
на 21/22 изображениях; средний SSIM вырос с 0.55 до 0.60. При этом он примерно на 13% медленнее
в контролируемом 800 px timing и на сцене 08 может давать заметную мозаичную микротекстуру.
Следовательно, это quality-кандидат, а не speed claim и не универсальная замена.

Оба варианта оставлены отдельными методами и отмечены как рекомендованные: старый Lab-L Laplacian
нужен как визуально более гладкий baseline, новый HSV Edge — как более резкая альтернативная
ветвь. Пользовательское сравнение не подменяется автоматическим выбором одного из них.

## Граница новизны

Gaussian/Laplacian pyramids, wavelet-разложения и Domain Transform — известные инструменты.
Проверяемая гипотеза проекта уже: training-free композиция HSV-V residual bands с одним
transmission/scale gate при общей физической части. Нельзя заявлять первым само разложение или
замену Laplacian на edge-aware/wavelet basis. Отсутствие найденного точного аналога этой композиции
не доказывает мировую новизну.
